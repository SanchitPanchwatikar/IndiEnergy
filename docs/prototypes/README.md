The mock-up contains demo interactions, including hardcoded OTP behavior, simulated authentication/payment, and unverified product/module claims. It loads third-party scripts from CDNs. Do not deploy it, collect real personal/payment/health data through it, or enter real credentials. Review and remove or replace prototype-only behavior before extracting any UI into an approved product.

The product boundary, claims, privacy, safety, and launch decisions in the backlog and approved ADRs take precedence over this visual prototype.
